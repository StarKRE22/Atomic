# 🧩 EventKey

**EventKey** is a strongly-typed identifier for events in an [IEventBus](Bus/IEventBus.md). It wraps an integer ID
generated by [EventKeyStore](EventKeyStore.md), providing type safety and avoiding repeated string lookups.

## 🧩 Overview

Event keys are typically defined once in a static API class and reused throughout the project. The bus type parameter
ensures that events can only be invoked or subscribed to on the correct bus implementation.

```csharp
public static class GameEventAPI
{
    public static readonly EventKey<IGameEventBus> PlayerTurnStarted = new(nameof(PlayerTurnStarted));
    public static readonly EventKey<IGameEventBus, SpawnEventArgs> EntitySpawned = new(nameof(EntitySpawned));
    public static readonly EventKey<IGameEventBus, IGameEntity> EntityDied = new(nameof(EntityDied));
}
```

---

## 🔍 Variants

| Struct | Description |
|--------|-------------|
| `EventKey<TBus>` | Parameterless event key for bus type `TBus`. |
| `EventKey<TBus, TArg>` | Single-argument event key. |
| `EventKey<TBus, TArg1, TArg2>` | Two-argument event key. |
| `EventKey<TBus, TArg1, TArg2, TArg3>` | Three-argument event key. |

> **Note:** `EventKey<TBus>` (parameterless) is declared inside a nested `Atomic.Events` namespace due to a historical
> namespace arrangement. The generic variants with arguments are directly in `Atomic.Events`.

## 🗂 Examples of Usage

### Define Event Keys

```csharp
public static class GameEventAPI
{
    // Game System
    public static readonly EventKey<IGameEventBus> PlayerTurnStarted = new(nameof(PlayerTurnStarted));
    public static readonly EventKey<IGameEventBus> PlayerTurnEnded = new(nameof(PlayerTurnEnded));

    // Game Entities
    public static readonly EventKey<IGameEventBus, SpawnEventArgs> EntitySpawned = new(nameof(EntitySpawned));
    public static readonly EventKey<IGameEventBus, IGameEntity> EntityDespawned = new(nameof(EntityDespawned));
    public static readonly EventKey<IGameEventBus, IGameEntity> EntityDied = new(nameof(EntityDied));
}
```

### Subscribe and Invoke

```csharp
IGameEventBus eventBus = context.GetValue(GameContextAPI.EventBus);

using var subscription = eventBus.Subscribe(GameEventAPI.PlayerTurnStarted, () =>
{
    Debug.Log("Player turn started");
});

eventBus.Invoke(GameEventAPI.PlayerTurnStarted);
```

### Parameterized Event

```csharp
using var subscription = eventBus.Subscribe(GameEventAPI.EntitySpawned, (SpawnEventArgs args) =>
{
    Debug.Log($"Spawned {args.Entity} at {args.Position}");
});

eventBus.Invoke(GameEventAPI.EntitySpawned, new SpawnEventArgs(entity, position));
```

## 🔍 API Reference

### EventKey\<TBus\>

```csharp
public readonly struct EventKey<TBus> : IEquatable<EventKey<TBus>> where TBus : IEventBus
```

> **Namespace:** `Atomic.Events.Atomic.Events`

#### `EventKey(string)`

```csharp
public EventKey(string name)
```

- **Description:** Creates an event key from a string name.
- **Parameter:** `name` — The event name.

#### `EventKey(int)`

```csharp
public EventKey(int id)
```

- **Description:** Creates an event key from an existing integer ID.
- **Parameter:** `id` — The numeric event identifier.

### EventKey\<TBus, TArg\>

```csharp
public readonly struct EventKey<TBus, TArg> : IEquatable<EventKey<TBus, TArg>> where TBus : IEventBus
```

Same API as `EventKey<TBus>`.

### EventKey\<TBus, TArg1, TArg2\>

```csharp
public readonly struct EventKey<TBus, TArg1, TArg2> : IEquatable<EventKey<TBus, TArg1, TArg2>>
    where TBus : IEventBus
```

### EventKey\<TBus, TArg1, TArg2, TArg3\>

```csharp
public readonly struct EventKey<TBus, TArg1, TArg2, TArg3> : IEquatable<EventKey<TBus, TArg1, TArg2, TArg3>>
    where TBus : IEventBus
```

## 📌 Best Practices

- Define event keys once in a static API class and reuse them.
- Use the bus type parameter to prevent cross-bus misuse.
- Keep event names stable; changing a name changes the generated ID unless a deterministic algorithm is used.
- Prefer extension methods (see [Extensions](Extensions.md)) over raw `.Id` access for readability.
