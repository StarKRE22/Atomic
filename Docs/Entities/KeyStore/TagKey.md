# 🧩 TagKey

Lightweight, strongly-typed identifiers for entity tags. `TagKey` wraps an integer ID generated by [EntityKeyStore](EntityKeyStore.md), avoiding repeated string lookups at runtime.

## 🗂 Example of Usage

```csharp
public static partial class GameEntityAPI
{
    public static readonly TagKey IsEnemy = new(nameof(IsEnemy)); // For IEntity
    public static readonly TagKey IsBoss = new(nameof(IsBoss)); // For IEntity
    public static readonly TagKey<IGameEntity> IsSelectable = new(nameof(IsSelectable)); // For specific entity type IGameEntity
}

// Usage
IEntity entity = ...;
entity.AddTag(GameEntityAPI.IsEnemy);

if (entity.HasTag(GameEntityAPI.IsEnemy))
    Debug.Log("Enemy detected!");

entity.DelTag(GameEntityAPI.IsEnemy);
```

## 🔍 API Reference

### 🏛️ Type

#### `TagKey`

```csharp
public readonly struct TagKey : IEquatable<TagKey>
```

- **Description:** General-purpose tag key for any entity.
- **Inheritance:** `IEquatable<TagKey>`
- **Notes:** Wraps an integer ID generated by [EntityKeyStore](EntityKeyStore.md).
- **See also:** [TagKey&lt;E&gt;](#tagkeye), [ValueKey](ValueKey.md), [IEntity Tag Extensions](../Entities/ExtensionsTags.md)

#### `TagKey<E>`

```csharp
public readonly struct TagKey<E> : IEquatable<TagKey<E>> where E : IEntity
```

- **Description:** Tag key bound to a specific entity type `E`.
- **Inheritance:** `IEquatable<TagKey<E>>`
- **Type Parameters:** `E` — The entity type. Must implement [IEntity](../Entities/IEntity.md).
- **Notes:** Prevents accidental mixing of keys between different entity types.
- **See also:** [TagKey](#tagkey), [ValueKey&lt;E, T&gt;](ValueKey.md), [IEntity Tag Extensions](../Entities/ExtensionsTags.md)

### 🏹 Methods

#### `ToString()`

```csharp
public override string ToString()
```

- **Description:** Returns the original tag name via [EntityKeyStore.IdToName](EntityKeyStore.md).
- **Returns:** The tag name.

#### `Equals(TagKey)`

```csharp
public bool Equals(TagKey other)
```

- **Description:** Determines whether the specified tag key is equal to the current one.
- **Parameter:** `other` — The tag key to compare.
- **Returns:** `true` if both keys have the same ID; otherwise, `false`.

#### `Equals(TagKey<E>)`

```csharp
public bool Equals(TagKey<E> other)
```

- **Description:** Determines whether the specified typed tag key is equal to the current one.
- **Parameter:** `other` — The tag key to compare.
- **Returns:** `true` if both keys have the same ID; otherwise, `false`.

#### `Equals(object)`

```csharp
public override bool Equals(object obj)
```

- **Description:** Determines whether the specified object is equal to the current tag key.
- **Parameter:** `obj` — The object to compare.
- **Returns:** `true` if the object is a matching tag key; otherwise, `false`.

#### `GetHashCode()`

```csharp
public override int GetHashCode()
```

- **Description:** Returns the hash code for the tag key.
- **Returns:** The hash code based on the internal ID.
