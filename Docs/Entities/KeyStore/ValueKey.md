# 🧩 ValueKey

Lightweight, strongly-typed identifiers for entity values. `ValueKey` wraps an integer ID generated by [EntityKeyStore](EntityKeyStore.md), enabling fast and type-safe value access without runtime string lookups.

## 🗂 Example of Usage

```csharp
public static partial class GameContextAPI
{
    public static readonly ValueKey<int> Score = new(nameof(Score)); // For base IEntity
    public static readonly ValueKey<IGameEntity, float> Health = new(nameof(Health)); For specific entity type IGameEntity
}

// Usage with IEntity
IEntity entity = ...;
entity.AddValue(GameContextAPI.Score, 100);
int score = entity.GetValue(GameContextAPI.Score);

// Usage with a typed entity
IGameEntity gameEntity = ...;
gameEntity.AddValue(GameContextAPI.Health, 100f);
float health = gameEntity.GetValue(GameContextAPI.Health);
```

## 🔍 API Reference

### 🏛️ Type

#### `ValueKey<T>`

```csharp
public readonly struct ValueKey<T> : IEquatable<ValueKey<T>>
```

- **Description:** Value key bound to a value type `T`. Can be used with any [IEntity](../Entities/IEntity.md).
- **Inheritance:** `IEquatable<ValueKey<T>>`
- **Type Parameters:** `T` — The type of the value associated with this key.
- **Notes:** Wraps an integer ID generated by [EntityKeyStore](EntityKeyStore.md).
- **See also:** [ValueKey&lt;E, T&gt;](#valuekeye-t), [TagKey](TagKey.md), [IEntity Value Extensions](../Entities/ExtensionsValues.md)

#### `ValueKey<E, T>`

```csharp
public readonly struct ValueKey<E, T> : IEquatable<ValueKey<E, T>> where E : IEntity
```

- **Description:** Value key bound to both an entity type `E` and a value type `T`.
- **Inheritance:** `IEquatable<ValueKey<E, T>>`
- **Type Parameters:**
  - `E` — The entity type. Must implement [IEntity](../Entities/IEntity.md).
  - `T` — The type of the value associated with this key.
- **Notes:** Prevents accidental misuse across different entity types.
- **See also:** [ValueKey&lt;T&gt;](#valuekeyt), [TagKey&lt;E&gt;](TagKey.md), [IEntity Value Extensions](../Entities/ExtensionsValues.md)

### 🏹 Methods

#### `ToString()`

```csharp
public override string ToString()
```

- **Description:** Returns the original value name via [EntityKeyStore.IdToName](EntityKeyStore.md).
- **Returns:** The value name.

#### `Equals(ValueKey<T>)`

```csharp
public bool Equals(ValueKey<T> other)
```

- **Description:** Determines whether the specified value key is equal to the current one.
- **Parameter:** `other` — The value key to compare.
- **Returns:** `true` if both keys have the same ID; otherwise, `false`.

#### `Equals(ValueKey<E, T>)`

```csharp
public bool Equals(ValueKey<E, T> other)
```

- **Description:** Determines whether the specified typed value key is equal to the current one.
- **Parameter:** `other` — The value key to compare.
- **Returns:** `true` if both keys have the same ID; otherwise, `false`.

#### `Equals(object)`

```csharp
public override bool Equals(object obj)
```

- **Description:** Determines whether the specified object is equal to the current value key.
- **Parameter:** `obj` — The object to compare.
- **Returns:** `true` if the object is a matching value key; otherwise, `false`.

#### `GetHashCode()`

```csharp
public override int GetHashCode()
```

- **Description:** Returns the hash code for the value key.
- **Returns:** The hash code based on the internal ID.
